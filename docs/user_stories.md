# Smart Clinic Management System

## User Stories

### Admin
1. As an Admin, I want to log in securely so that I can access the admin dashboard.
2. As an Admin, I want to add new doctors to the system so that patients can book appointments with them.
3. As an Admin, I want to view all appointments so that I can monitor clinic activity.

### Doctor
1. As a Doctor, I want to log in securely so that I can view my schedule.
2. As a Doctor, I want to view my appointments for a specific date so that I know who I am treating today.
3. As a Doctor, I want to create a prescription for a patient so that they can get their medication.

### Patient
1. As a Patient, I want to log in securely so that I can access my dashboard.
2. As a Patient, I want to search for doctors by specialization so that I can find the right specialist.
3. As a Patient, I want to book an appointment with a doctor so that I can get medical consultation.
4. As a Patient, I want to view my prescriptions so that I know what medication to take.
